# CyberNova — Web & AI Solutions

Multi-page responsive website (HTML, CSS, JavaScript — no build step).

## Pages
`index.html` · `services.html` · `work.html` · `about.html` · `faq.html` · `contact.html` · `404.html`

## Configure
Edit the `CONFIG` block at the top of `script.js`:
- `accessKey` — Web3Forms access key (contact form)
- `email`, `whatsapp` (country code, no + or leading 0), `github`

## Run locally
Open `index.html` in a browser.

## Deploy on GitHub Pages
Settings → Pages → Deploy from a branch → `main` / root.
